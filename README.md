# CPS — Embedded Real-Time Systems

This repository contains the assignments and projects developed for the **Embedded Real-Time Systems** course at the University of Tehran.

The projects focus on communication protocols, embedded systems, smartphone sensors, real-time processing, and performance analysis.

## Assignments

### Assignment 1 — Communication Protocol Simulation

Simulation and implementation of communication protocols in a custom embedded-system environment.

Topics covered:

* C2I communication
* Full-Duplex USART
* C2I Multiplexer
* Protocol-level communication and data transfer
* C++20-based simulation

`Communication-Protocols-Simulation/`

### Assignment 2 — Air Mouse

An Android-based **Air Mouse** that uses smartphone sensors to control a computer mouse wirelessly.

Topics covered:

* Gyroscope, accelerometer, and magnetometer
* Sensor calibration and fusion
* Cursor movement, clicking, and scrolling
* UDP-based communication
* Android application development
* Performance analysis with Perfetto

`Air-Mouse-Android/`
